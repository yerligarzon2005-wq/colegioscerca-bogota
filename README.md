# ColegiosCerca Bogotá

Aplicación web (Java + Spring Boot) para buscar colegios de Bogotá.

**Fuente de datos:** LISTADO COLEGIOS BOGOTA (`qijw-htwa`), datos.gov.co, MinEducación.
**Nota:** los datos son del año 2016.

## Cómo ejecutar
Requisitos: Java 17 o superior y Maven.

    mvn spring-boot:run

Abrir http://localhost:8080
